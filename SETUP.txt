CSIT314 Fundraising App - Setup Guide (Windows)
=================================================

REQUIREMENTS
------------
Install these before starting:
- Node.js (v18 or later): https://nodejs.org
- Git: https://git-scm.com

After installing, open Command Prompt and check:
    node -v
    npm -v
    git --version


STEP 1 - Clone the Repo
------------------------
Open Command Prompt and run:

    git clone https://github.com/GlennNeoShiHeng/CSIT314.git
    cd CSIT314


STEP 2 - Start the Backend
---------------------------
In the same terminal:

    cd backend
    npm install
    node src/seed.js
    npm run dev

You should see: Server running at http://localhost:3001
Leave this terminal open.


STEP 3 - Start the Frontend
-----------------------------
Open a SECOND Command Prompt window:

    cd path\to\CSIT314\frontend
    npm install
    npm run dev

You should see: VITE ready at http://localhost:5173


STEP 4 - Open the App
----------------------
Go to http://localhost:5173 in your browser.

  - Create a new fundraising category (Story #42)

  - Delete a category (Story #44)

  - Enter an amount and payment method

TROUBLESHOOTING
---------------
- If "node is not recognized": restart your computer after installing Node.js
- If port 3001 is in use: open backend\src\config.js and change the PORT number
- If npm install fails: run Command Prompt as Administrator
- If login fails: make sure you ran "node src/seed.js" in the backend folder first
